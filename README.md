Aplicação web simples para calcular qual combustível é mais vantajoso: gasolina ou etanol.

## Como funciona

O sistema compara os preços informados e usa a regra:

- se o etanol for menor ou igual a 75% do preço da gasolina, o melhor é etanol;
- caso contrário, a melhor opção é gasolina.

## Tecnologias

- Python
- Flask
- HTML
- Bootstrap

## Instalação

```bash
git clone https://github.com/seu-usuario/Cobra-Flex.git
cd Cobra-Flex
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Acesse: `http://127.0.0.1:5000/`
